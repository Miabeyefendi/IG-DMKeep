# IG-DMKeep

**Сохраните свои переписки в Instagram, пока они не потерялись. Полная история с временными метками, отправителями, реакциями и медиа, экспорт в JSON, TXT, Markdown или ZIP. Всё происходит в вашем браузере.**

## ✨ Главное

- **Ваши данные остаются вашими** - всё работает локально в браузере. Ни сервера, ни расширения, ни ключа API, ни аналитики. Ничто из ваших переписок не покидает вашу машину.
- **Интерфейс, а не стена вывода в консоли** - в страницу встраивается панель, из которой вы управляете сканированием, фильтруете ленту и выбираете, что экспортировать.
- **Четыре формата экспорта** - JSON для обработки, TXT для чтения, Markdown для публикации или ZIP, который упаковывает медиа вместе с текстом.
- **Медиа, которое страница вам не показывает** - инструмент слушает сетевые запросы и `PerformanceObserver`, чтобы достать прямые ссылки на reels, голосовые сообщения и изображения в полном разрешении, которых в DOM нет вовсе.
- **Голосовые сообщения текстом** - отдельный режим собирает собственные расшифровки Instagram, чтобы по экспорту можно было искать.
- **Фильтруйте и ищите до экспорта** - находите сообщения по слову или сужайте ленту только до изображений, аудио или reels.
- **Экспорт выборки, а не только всего** - отметьте те сообщения, которые вам действительно нужны.
- **Вывод на вашем языке** - заголовки в файле следуют выбранному языку, так что турецкий экспорт пишет `Gönderilen:`, а не `Sent:`.
- **Переживает виртуальную прокрутку** - Instagram выгружает сообщения по мере прокрутки; сканирование построено с учётом этого, а не вопреки.

## 🚀 Быстрый старт

1. Откройте [www.instagram.com](https://www.instagram.com/) на компьютере и войдите в аккаунт.
2. **Откройте ту переписку, которую хотите сохранить.** Скрипт читает разговор, который сейчас на экране, поэтому этот шаг не опциональный.
3. Откройте консоль. `F12` или `Ctrl + Shift + J` в Chrome и Edge, `Ctrl + Shift + K` в Firefox. На Mac `Cmd + Option + J`.
4. Вставьте [`instadm-scraper-v2.js`](./instadm-scraper-v2.js) целиком и нажмите Enter.
5. Появится панель. Запустите сканирование, дождитесь, пока оно пройдёт по переписке назад, затем выберите формат экспорта.

> **Если вы видите «Conversation container not found», значит вы не внутри переписки.** Открыть входящие недостаточно. Зайдите в конкретный диалог, дождитесь отрисовки сообщений и только затем вставляйте скрипт.

## ⚙️ Настройка

Всё задаётся в панели, в файле ничего править не нужно.

| Группа | Параметр | Что делает |
|---|---|---|
| Export | Format | JSON, TXT, Markdown или ZIP |
| Export | Selection | Вся переписка или только отмеченные сообщения |
| Export | Language | Язык заголовков, которые пишутся в файл экспорта |
| Filter | Keyword | Показывать только сообщения с определённым словом или фразой |
| Filter | Type | Только изображения, только аудио или только reels |
| Media | Download media | Скачать сами файлы и упаковать их в ZIP |
| Media | Transcription | Собрать расшифровки Instagram для голосовых сообщений |

Как каждый из них устроен внутри и что делать, когда что-то из этого сбоит, описано в [руководстве](./TUTORIAL_RU.md).

## ❓ Частые вопросы

<details>
<summary><b>«Conversation container not found. Open a DM thread first.»</b></summary>

Скрипт не нашёл на странице отрисованную переписку. Одного входа в аккаунт или нахождения в списке входящих недостаточно. Откройте конкретный диалог, дождитесь, пока сообщения станут видимыми, и только затем вставляйте скрипт. Если диалог открыт, а ошибка остаётся, значит Instagram изменил разметку; заведите issue и укажите версию браузера.

</details>

<details>
<summary><b>Отправляет ли это мои сообщения куда-то?</b></summary>

Нет. Всё выполняется на уже открытой у вас странице, а файл экспорта пишет ваш собственный браузер на ваш диск. Ни сервера, ни расширения, ни аналитики. Ровно поэтому это консольный скрипт.

</details>

<details>
<summary><b>Могу ли я выгрузить чужие переписки?</b></summary>

Нет. Скрипт способен прочитать только то, что и так может показать ваша собственная авторизованная сессия. Это способ сохранить копию своих разговоров, не более.

</details>

<details>
<summary><b>Почему ZIP собирается так долго?</b></summary>

Потому что он скачивает сами медиафайлы по одному и упаковывает их прямо в браузере. Длинная переписка с большим количеством reels и голосовых это заметный объём трафика. Текстовый экспорт занимает почти мгновение.

</details>

<details>
<summary><b>Некоторые старые сообщения отсутствуют.</b></summary>

Instagram выгружает сообщения по мере прокрутки, поэтому сканированию приходится идти по переписке назад, чтобы вернуть их на страницу. Дайте ему закончить. На очень длинных диалогах это занимает время.

</details>

<details>
<summary><b>v1 или v2?</b></summary>

v2, если только вам не нужно что-то настолько компактное, что читается за один присест. v1 это 342 строки и обычный текст; v2 это полноценный инструмент.

</details>
